## 트리 기초 + 백준 1991 - 트리 순회


### 개념 정리
- 트리는 사이클이 없는 연결 그래프. N개 노드면 항상 N-1개의 간선을 가짐(크루스칼 때
  다룬 MST와 같은 성질)
- 용어: 루트(부모 없는 최상위 노드), 리프(자식 없는 노드), 깊이(루트로부터의 거리)
- 트리 순회 3가지는 "자기 자신을 언제 처리하느냐"의 차이일 뿐, 구조는 DFS 재귀와 동일
    - 전위(Preorder): 나 → 왼쪽 → 오른쪽
    - 중위(Inorder): 왼쪽 → 나 → 오른쪽
    - 후위(Postorder): 왼쪽 → 오른쪽 → 나

### 문제 - 백준 1991 (트리 순회)
- 각 줄에 "노드 왼쪽자식 오른쪽자식" 형태로 입력이 주어지고, 이를 전위/중위/후위로
  각각 출력하는 문제. 이 문제는 관례상 루트가 항상 'A'로 고정되어 있음(일반적인 트리
  문제에서는 루트를 별도로 지정하거나 직접 정해야 함을 확인)
- Map<Character, char[]>로 각 노드의 왼쪽/오른쪽 자식을 저장하고, Tree 클래스로
  데이터와 순회 로직을 캡슐화하여 구현
- 세 가지 순회 함수 모두 "나를 처리하는 위치"만 다르게 재귀로 구현, '.'을 만나면
  재귀 종료


## 회고
- 트리 순회가 이미 익숙한 DFS 재귀 패턴의 변형이라는 것을 바로 캐치해서 실수 없이
  한 번에 완성함. "나를 처리하는 위치"라는 하나의 축으로 세 가지 순회를 구분해서
  외우는 방식이 효과적이었음
- 이번 주제는 카카오 코테 대비 우선순위상 깊이 파기보다 기초만 짚고 넘어가기로 함.
  이후 문자열/구현 유형에 시간을 집중할 계획
