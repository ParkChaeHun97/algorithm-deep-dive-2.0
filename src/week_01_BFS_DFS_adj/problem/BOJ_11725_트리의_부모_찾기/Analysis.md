## 1. 문제 요약
- 트리가 주어지고, 트리의 루트가 1이라고 정했을때, 각 노드의 부모 구하기

## 2. 입력
```text
7
1 6
6 3
3 5
4 1
2 4
4 7
```


## 3.문제 분석 및 해결 방법
- root가 1이라고 하니 가장 부모는 1임  
- 결국 깊이 들어갈수록 들어가기 전의 노드 번호가 부모임

- 지난번에 해결한 연결 요소의 개수에서 dist[] 라는 배열을 사용해서 최적화하는 기법을 배운 것을 활용해보자
- 방문처리만 제대로 된다면 bfs와 dfs 둘 중 하나로 순회하면 될듯
- parant[] 배열을 만들어서 다음 parent[다음노드 번호] = 현재 노드 번호로 처리한다.  
- parant[] 배열을 2번부터 N번까지 출력하기


## 4. 시간 복잡도
- N은 최대 100,000
- 간선 연결: O(N-1) x 2 = 199,998번
- dfs: O(V + E) = 100,000 + (99,999 x 2 (양방향 연결)) = 299,998번
- append: O(N-2) = 99,998번
- 199,998(입력) + 299,998(DFS) + 99,999(출력) = 599,995번




## 5. 디테일 채우기
- visited[] 배열은 필요 없음
  - parents 배열은 0으로 초기화 되어있기 때문에 if(!visited[next.id]) 대신 if(parents[next.id] == 0) 으로 검사하면 부모가 아직 없는 노드가 미방문 노드가 된다.
  - visited 배열 크기 만큼 메모리를 아낄 수 있음
- Node 클래스 지우기
  - Node 안에 List<Node> adj를 넣었는데 N이 10만일 때 노드 객체 10만 개 생성하는 것은 힙(Heap) 메모리에 큰 부하를 줌
  - 굳이 객체로 안 만들고 전역 변수로 ArrayList<Integer>[] adj; 형식 원시 타입 인접 리스트 배열을 사용하면 메모리와 속도가 빨라짐
  - 하지만 Node 클래스가 있으면 시인성과 java의 특성인 객체지향을 살릴 수 있다고 생각함.
