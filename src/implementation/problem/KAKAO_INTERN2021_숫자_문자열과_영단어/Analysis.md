## 숫자 문자열과 영단어 (2021 KAKAO 채용연계형 인턴십)

### 문제
숫자와 영단어(zero, one, two, ..., nine)가 섞여 있는 문자열이 주어질 때, 영단어를 숫자로 바꿔서 전체를 정수로 반환하는 문제.

### 접근
- `replaceAll()`을 0부터 9까지 순서대로 체이닝하여, 각 영단어를 해당 숫자로 치환
- 치환이 다 끝난 문자열을 `Integer.parseInt()`로 정수 변환해 반환

### 특이사항
- 별다른 시행착오 없이 한 번에 완성
- 치환 순서(zero→one→two...)가 서로 겹치는 부분 문자열이 없어(zero, one, two, three... 각 영단어가 서로의 substring이 아님) 순서와 무관하게 안전하게 동작함

## 회고
- 짧고 간단한 문제로, 문자열 치환 체이닝을 활용해 빠르게 해결함
