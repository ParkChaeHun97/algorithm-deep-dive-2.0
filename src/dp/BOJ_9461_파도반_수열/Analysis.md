# Day 5 - 파도반 수열

## 백준 9461 (파도반 수열)

### 문제
- 나선 모양으로 놓인 정삼각형의 변의 길이 수열 P(N) 출력
- P(1)~P(10): 1, 1, 1, 2, 2, 3, 4, 5, 7, 9

### 해결
- 점화식: `dp[i] = dp[i-1] + dp[i-5]`
- base case: dp[1]=1, dp[2]=1, dp[3]=1, dp[4]=2, dp[5]=2
- 미리 dp[1]~dp[100] 전부 채워두고 T번 O(1) 조회
- O(N) + O(1) * T 로 해결

### 핵심 포인트
- 수열 나열해서 몇 번째 전 항들의 합인지 직접 유도
- N=100일 때 값이 int 범위(약 21억) 초과 → long 필수
- 피보나치, 1,2,3 더하기와 동일한 "미리 계산 후 조회" 패턴
