# 최댓값과 최솟값 (프로그래머스 Lv2, 연습문제)

## 문제

공백으로 구분된 숫자들이 담긴 문자열 s에서 최솟값과 최댓값을 찾아 `"(최솟값) (최댓값)"` 형태의 문자열로 반환하기.

## 접근

- `split(" ")`으로 숫자 문자열을 쪼개서 `Integer.parseInt`로 변환하고, 한 번 순회하면서 `Math.max`, `Math.min`으로 갱신. 시간복잡도는 O(n)
- 초기값을 `Integer.MIN_VALUE`(최댓값용), `Integer.MAX_VALUE`(최솟값용)로 잡아서 첫 원소와 비교할 때도 안전하게 갱신됨
- `Integer.parseInt`가 `"-1"` 같은 음수 문자열도 처리해줘서 부호 처리를 따로 안 해도 됨
- 반환은 `minValue + " " + maxValue`로 문자열을 이어 붙임. 최솟값이 먼저 나오는 순서만 주의

## 헷갈렸던 지점

- 없음

## 실수

- 없음. 시행착오 없이 풀었음

## 회고

- 쉬운 문제로 감을 풀어주는 용도였음. 최댓값/최솟값 초기값을 `MIN_VALUE`/`MAX_VALUE`로 반대로 잡는 패턴을 그대로 적용함
- 참고로 스트림으로도 풀 수 있음. `Arrays.stream(split).mapToInt(Integer::parseInt).summaryStatistics()`를 쓰면 `getMin()`, `getMax()`로 한 번에 꺼낼 수 있는데, 이번엔 안 써봤음. 스트림 연습용으로 다시 풀어볼 만함
- `split(" ")`은 공백이 연속으로 들어오면 빈 문자열이 생겨서 `parseInt`에서 예외가 날 수 있음. 연속 공백까지 처리해야 하는 문제라면 `split("\\s+")`를 써야 함
