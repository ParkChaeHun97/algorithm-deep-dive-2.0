# 1. 시간 복잡도 분석

- 누적합 배열 만들기 - O(N)
- K일간의 매출 합 중 최대값 구하기 - O(N)
- 최종 시간 복잡도 - O(2N)


# 2. 회고
- 처음에는 O(N)으로 K일 만큼 누적합 배열로 만들면서 값을 바로 구하려고 했음
- 하지만 누적합 배열을 만드는 중 단순 날짜의 매출이 필요했음
- Current + prefixSum[i-1] - prefixSum[i-k]로 구할 수 있을 줄 알았지만
- prefixSum[i-k]인 누적합 값이 아니라 단순 해당 날짜의 매출 값이 필요했음
- 그래서 N만큼 모든 날짜의 누적합을 만든 다음 prefixSum[i] - prefixSum[k]를 max값으로 비교하여 최댓값을 구함
- 구간 합 구하기 4만큼 단순하며 똑같은 문제였음
