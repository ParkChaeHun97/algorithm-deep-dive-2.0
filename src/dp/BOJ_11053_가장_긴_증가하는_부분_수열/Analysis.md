## 백준 11053 (LIS 기초)

### 문제
- 주어진 수열에서 가장 긴 증가하는 부분 수열의 길이 구하기

### 해결
- `dp[i]` = i번째 원소를 **마지막으로** 하는 LIS의 길이
- i 이전의 모든 j에 대해 A[j] < A[i]일 때 dp[j] + 1을 후보로 놓고 최댓값 선택
- 점화식: `dp[i] = max(dp[j] + 1)` (단, A[j] < A[i])
- O(N²)으로 해결

### 핵심 포인트
- 부분 수열은 연속일 필요 없음 (예: {10, 20, 30, 50}은 원본에서 비연속)
- N=1,000이라 O(N²) 충분하지만, N이 크면 O(N log N) LIS 알고리즘 필요
- dp 배열을 sort한 뒤 마지막 값이 최댓값 (모든 dp[i] 중에서)
