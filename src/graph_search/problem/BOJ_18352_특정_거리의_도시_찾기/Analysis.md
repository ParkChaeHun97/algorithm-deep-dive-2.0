# 분석

## 1. 문제 요약
- 1번부터 N번 까지의 도시, M개의 단방향 도로가 존재
- 특정 도시 X 출발, 도달할 수 있는 도시 중, 최단 거리가 정확히 K인 모든 도시의 번호를 출력
- X에서 X로 가는 최단 거리는 0
- X로부터 출발하여 도달할 수 있는 도시 중 최단 거리가 K인 모든 도시의 번호를 '한 줄에 하나씩 오름차 순'으로 출력

## 2. 입력
- 첫째 줄 : 도시의 갯수 N, 도로의 개수 M, 거리 정보 K, 출발 도시의 번호 X 주어짐
- 둘째 줄 : M개의 줄에 걸쳐서 두개의 자연수 A,B 공백 기준으로 구분
- '단방향' A!=B


## 3. 시간 복잡도
- N = 2 <= 300,000 (도시의 갯수)
- M = 1 <= 1,000,000 (도로의 개수)
- K = 1 <= 300,000 (거리 정보)
- X = 1 <= N(300,000) ( 출발 도시의 번호 X)

- 정렬 복잡도 O(M log M) + O N(N log N)
  - (1,000,000 x log2 1,000,000) + (300,000 x log2 300,000)
  - 20,000,000 + 5,400,000 = 25,400,000번
- BFS탐색 복잡도 O(V + E)
  - (next.weight == K) continue 가 K를 초과하는 값은 탐색하지 않는 가지치기
  - 300,000 + 1,000,000 = 1,300,000번
- 총 시간 복잡도 25,400,000 + 1,300,000 = 2,670만 번

## 5. 디테일 채우기

### dist[] 배열 사용하여 최적화하기

```java
static int[] dist; // 전역변수로 int[] dist 선언 필요

static void bfs(int start) {
    dist = new int[N + 1];
    Arrays.fill(dist, -1); // -1로 초기화 (방문 안 함)
    
    Queue<Node> queue = new LinkedList<>();
    queue.offer(nodes[start]);
    dist[start] = 0; // 출발지는 거리 0

    while (!queue.isEmpty()) {
        Node current = queue.poll();

        // 현재 거리가 이미 K이면 더 이상 자식을 큐에 넣을 필요 없음 (가지치기)
        if (dist[current.id] == K) continue; 

        for (Node next : current.adj) {
            if (dist[next.id] == -1) { // 방문하지 않은 노드라면
                dist[next.id] = dist[current.id] + 1; // 부모 거리 + 1
                queue.add(next);
            }
        }
    }
}
```

- dist 배열을 사용해서 -1로 초기화 하고
- dist[current.id] == K 면 큐에 넣지 않고 
- -1인(방문하지 않은) 경우는 next.id에 current.id + 1을 next에 넣는다.
- 반복문 돌려서 dist[i] == K면 현재 idx를 sb에 넣고 개행한다.
- 출력한다.
- 배열 초기화 비용 O(N), BFS 탐색 비용 O(N + M), 순차 탐색 비용(O(N))
- O(N) + O(N + M) + O(N) = O(3N + M)
- 900,000 + 1,000,000 = 약 190만 번

## 6. 느낀점
- 객체지향을 집착해서 weight 변수를 추가하여 고민 끝에 완성했지만 시간 복잡도가 굉장히 많이 나왔음
- dist[] 배열을 사용함으로써 정렬의 필요성 자체가 사라졌고, 약 93% 최적화가 되는 것을 몸소 체감함
- 자료구조 선택이 참 중요하다고 느꼈음
- 기존 코드도 제한 조건(1억 번) 안에는 들어오도록 체계적으로 설계했지만, 여기에 안주하지 않고 최적화를 고민함
- 작성한 코드의 부족함을 마주하는 것은 부끄러운 일이 아님, 내 로직이 최선이라고 자만하지 않고, 유연한 사고로 더 나은 대안을 수용할 때 실력이 폭발적으로 성장한다는 것을 배움
