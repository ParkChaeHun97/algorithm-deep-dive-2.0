# algorithm-deep-dive-2.0

대기업 2026 하반기 신입공채를 목표로 진행 중인 알고리즘 학습 레포입니다.
정답 코드만 남기는 게 아니라, **풀이 과정에서의 시행착오와 헷갈렸던 지점을 `Analysis.md`에 기록**하는 것을 원칙으로 합니다.

## 학습 원칙

- **30분 룰**: 문제를 받으면 최소 30분은 힌트 없이 스스로 붙잡고 고민한 뒤에만 풀이를 검색한다.
- **기록 우선**: 풀고 끝내지 않고, 왜 막혔는지 · 어떤 오답을 거쳤는지 · 무엇을 깨달았는지를 `Analysis.md`에 남긴다.
- **손으로 그리기**: 재귀 호출 스택, 그래프 탐색 순서처럼 헷갈리는 흐름은 그림으로 먼저 그려보고 코드로 옮긴다.
- **세션마다 커밋**: 학습 세션이 끝나면 그날의 진행 상황을 커밋으로 남긴다.

## 폴더 구조

```
src/
├── recursive/                        재귀 기초 (팩토리얼, 피보나치 등 워밍업)
├── dp/                                동적 계획법 (Top-down / Bottom-up 비교 포함)
├── week_01_BFS_DFS_adj/               BFS/DFS, 인접 리스트
├── week_02_Math/                      수학 (구간 합, 누적합 등)
├── week_03_number_theory/             정수론 (GCD/LCM, 에라토스테네스, 소인수분해)
├── week_04_binary_search_parameters/  이분 탐색 / 파라메트릭 서치
├── week_05_two_pointer_sliding_window/ 투 포인터 / 슬라이딩 윈도우
└── kakao_prablom/                     카카오 기출 문제 (블라인드 채용 등)
```

각 문제 폴더는 기본적으로 아래 구성을 따릅니다.

```
BOJ_XXXX_문제이름/
├── Solution.java     (또는 TopDown.java / BottomUp.java 등 풀이 방식별 구분)
└── Analysis.md        문제 요약 · 접근 · 시행착오 · 핵심 교훈
```

## 진행 현황

| 주차 / 카테고리 | 주제 | 기록된 문제 수 |
|---|---|---|
| Week 01 | BFS / DFS / 인접 리스트 | 5 |
| Week 02 | 수학 | 4 |
| Week 03 | 정수론 | 5 |
| Week 04 | 이분 탐색 / 파라메트릭 서치 | 4 |
| Week 05 | 투 포인터 / 슬라이딩 윈도우 | 1 (진행 중) |
| DP | Top-down / Bottom-up | 10 |
| 카카오 기출 | 블라인드 채용 등 | 2 |

> 13주 전체 계획 (카카오 9월 공채 코테 대비, 하루 2~3시간 · 평일 기준):
> Week 1~2 구간합/에라토스테네스 → Week 3 정수론 심화 (**DP 병행 시작**) → Week 4 이분 탐색/파라메트릭 서치 → Week 5 투 포인터/슬라이딩 윈도우 → Week 6 자료구조/그리디 → Week 7 최단 경로(다익스트라·유니온파인드) → Week 8 DP 집중 심화 → Week 9 카카오식 문자열 파싱 → Week 10 삼성식 시뮬레이션 → Week 11 배민/당근 기출 → Week 12 카카오 기출 집중 → Week 13 마무리/멘탈 관리.
> DP는 3주차부터 매일 병행 문제로 시작해 8주차에 집중 심화. 현재 5주차 진행 중.

## Analysis.md 작성 예시

```markdown
## BOJ_1463 - 1로 만들기 (Top-down)

### 문제
- 정수 N을 1로 만드는 최소 연산 횟수

### 헷갈렸던 지점
- dp(n-1) 호출 시 바로 값이 정해지는 게 아니라, base case까지 내려갔다 올라와야 확정됨

### 코드 작성 중 발생했던 실수들
1. memo 값을 다시 dp()에 넣는 실수
2. ...

### 회고
- Bottom-up은 점화식을 세우기 쉬웠지만, Top-down은 재귀 호출 흐름 이해가 선행되어야 했음
```
