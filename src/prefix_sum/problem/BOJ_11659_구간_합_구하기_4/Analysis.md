## 2. 시간 복잡도 분석

![누적합](./src/week_02_Math/BOJ_11659_구간_합_구하기_4/누적합.png)

- 배열 A에서 누적합을 구하려면 일반적으로 O(N)이 걸림
  - for(i = 3; i <= 5; i++)해서 누적합을 구하면됨
    - 하지만 1에서 N만큼 누적합을 구하려면 결국 시간복잡도는 O(N)임
- 하지만 메모이제이션을 통해 누적합 값을 미리 구해 놓으면 O(1)이 걸림
  - 배열에 입력 받을 때 prefixSum[i] = prefixSum[i-1] + current;로 입력받고
  - 누적합을 구할땐 prefixSum[b] - prefixSum[a-1]
    - 즉 5번의 누적합 - 3-1번의 누적합을 구하면
    - 3번부터 5번 까지의 합이 나옴
