## 백준 11047 - 동전 0

### 문제
동전 N종류로 K원을 만드는데 필요한
최소 동전 개수를 구하는 문제. 동전 가치는 오름차순이며,
A1=1이고 1>=2일 때 A[i]는 A[i]-1의 배수. 그리디가 성립

### 접근
 - 큰 동전부터 최대한 많이 사용하는 그리디 전략
 - 입력을 오름차순 그대로 받되, 배열 인덱스를 거꾸로 채워서 배열 자체가 내림차순이 되도록 구성함
 - 순회하면서 K를 coins[i]로 나눈 몫만큼 개수 누적, 나머지로 K 갱신
 - K==0이 되면 조기 종료

### 헷갈렸던 지점
- 왜 큰 동전부터 쓰는 그리디가 항상 최적인가에 대한 증명이 처음엔 애매모했음 직접 증명 과정을 따라가며 이해함
  - 동전 B가 동전 A의 배수일 때 B원을 A로 채우려면 정확히 n개 필요
  - 동전 종류가 다르다는 건 B > A임 n은 항상 2이상임
  - 즉 B가 1개 vs A n개 -> 무조건 1개 쓰는 쪽이 개수가 적음
  - 배수 관계가 사슬처럼 이어져 있어 이 논리가 일반화됨
  - 배수 관계일 때만 그리디가 최적해를 보장

- 그리디 vs DP 판단 기준
  - 동전이 배수관계로 이어짐 (1,5,10,50) -> 그리디
  - 배수 관계 아닌 임의 값 (1,3,4,7) -> 그리디 실패 가능성, DP 필요
  - 반례 확인해보면 [1,3,4], k=6 이면 그리디 4+1+1 3개, 최적은 3+3 2개
