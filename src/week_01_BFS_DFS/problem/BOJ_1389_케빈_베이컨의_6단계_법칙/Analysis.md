# 분석

## 1. 문제 요약
- 1번 부터 N번까지 N명의 사람이 있음
- 이들 사이에 간선이 주이짐
- 특정 노드 X의 케빈 베이컨 수란 X에서 출발하여 모든 사람에게 도달하기 위한 최단 거리의 총합

## 2. 입력
- 첫째 줄 유저의 수 N(2 <= N <= 100) 친구 관계의 수(1 <= M <= 5,000)
- 둘째 줄 부터 M개 줄에는 서로 친구인 두 사람의 번호 A,B가 주어짐
- 간선의 가중치는 모두 1, 양방향 간선

## 3. 문제 해결
- dist[] -> 노드 출발점 부터 다른 노드까지 가중치를 저장할 용도로 사용
- sumArray[] -> dist에 저장된 가중치의 모든 합을 노드 시작점 idx에 저장할 용도로 사용
- dfs를 사용하면 재귀과정에서 깊이가 깊은곳부터 들어가기때문에 가중치 값이 이상하게 저장되기 때문에 bfs를 사용
- 해결 방법
  1. dist 배열을 -1로 초기화
  2. bfs 시작
     1. start를 인자값을 받고
     2. dist[start] = 시작 노드의 가중치는 0으로 선언
     3. 시작점의 인접 리스트를 꺼내고
     4. 다음 방문할 노드 값이 -1이면
     5. 현재 노드의 값 + 1로 초기화 하고 큐에 넣음
        - 현재 노드 값 + 1이면 다음 깊이에는 +2, +3 순으로 깊어짐
  3. dist에 저장된 각각 가중치를 모두 더하고 더한 값을 sumArray에 삽입
  4. 가중치중 가장 작은 값을 선정해 minIdx에 저장
