# 분석

## 1. 문제 요약
- 무방향 그래프에서 연결 요소 구하기.

## 2. 입력
- 첫째 줄 정점의 개수 N, M
- 둘째 줄 부터 M개의 u, v (같은 간선은 한 번만 주어짐)

## 3. 시간 복잡도
- 1 <= N <= 1,000
- 0 <= M <= N x(N-1) / 2 
- dfs는 O(V + E)
- 1,000 + (1000 x 999 / 2) = 약 500,500번의 연산

## 4. 문제 해결
- 요소의 개수만큼 for문을 돌린다.
  - 방문하지 않은 요소만 순회하고 count를 올린다.

## 5. 디테일 채우기
- u와 v를 전역 변수로 선언했었는데, for문 내부에 지역 변수로 선언하는 것으로 변경
  - 전역 변수가 많아지면 메모리를 계속 잡고있으며 규모가 커지면 메서드와 변수명이 꼬일 수 있는 가능성이 있음
