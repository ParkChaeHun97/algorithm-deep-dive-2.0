# 최솟값 만들기 (프로그래머스 Lv2, 연습문제)

## 문제

길이가 같은 두 배열 A, B에서 각각 한 개씩 뽑아 곱하고, 이걸 배열 길이만큼 반복해서 누적합이 최소가 되게 하기. 같은 인덱스는 한 번씩만 뽑을 수 있음.

## 접근

- A와 B를 둘 다 오름차순 정렬한 뒤, `A[i] * B[B.length-1-i]`로 짝지어서 더함. 가장 작은 수는 가장 큰 수와, 가장 큰 수는 가장 작은 수와 곱해야 곱의 합이 최소가 되는 그리디
- B를 내림차순으로 정렬하지 않고 오름차순 정렬 후 뒤에서부터 읽어서 처리. `int[]`는 `Comparator`를 못 써서 내림차순 정렬하려면 `Integer[]`로 바꿔야 하는데, 인덱스만 뒤집으면 그럴 필요가 없었음
- 시간복잡도는 정렬이 지배해서 O(n log n)
- 합이 int 범위를 넘는지 확인했는데, 제한이 크기 1,000 이하, 원소 1,000 이하라 최악이 1000 * 1000 * 1000 = 10억이라 int로 충분했음

## 헷갈렸던 지점

- 없음

## 실수

- 없음. 시행착오 없이 풀었음

## 회고

- "큰 것과 작은 것을 짝지으면 곱의 합이 최소"라는 그리디 감각으로 바로 풀었음. 반대로 최대로 만들고 싶으면 둘 다 같은 방향으로 정렬해서 짝지으면 됨
- 쉬운 문제로 감을 풀어주는 용도였고, 반례 검증이 필요한 구간이 없었음
