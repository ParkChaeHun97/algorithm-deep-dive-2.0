# 1463 - 1로 만들기 (Top-down)

## 문제
- 정수 N을 1로 만드는 최소 연산 횟수 (3으로 나누기 / 2로 나누기 / 1 빼기)
- 동일 문제를 Bottom-up에 이어 Top-down(재귀+메모이제이션)으로 재구현

## 핵심 포인트

### Bottom-up vs Top-down 구조 차이
- Bottom-up: 1부터 N까지 순서대로 테이블을 채워나감
- Top-down: dp(N) 호출 → 재귀로 base case까지 내려갔다가, 올라오면서 계산 + memo 저장

### 헷갈렸던 지점
- `current = dp(n-1) + 1` 줄을 만나는 순간 바로 값이 정해지는 게 아니라, **dp(n-1)이 끝까지 재귀를 타고 내려가서 base case에 도달한 뒤 다시 올라와야 비로소 current 값이 확정됨**
- 즉 "내려갈 때는 계산 없음, 올라올 때 계산 발생"이 Top-down의 본질
- 손으로 호출 스택을 그려보며(dp(5)→dp(4)→dp(3)→dp(2)→dp(1)) 내려가는 화살표와, 값이 확정되며 올라오는 화살표를 분리해서 그려보니 구조가 명확해짐

### 코드 작성 중 발생했던 실수들
1. `dp(memo[n/3] + 1)` 처럼 memo 값을 다시 dp()에 넣는 실수 → memo는 저장소일 뿐, 호출은 항상 `dp()`로 해야 함
2. `current % 3 == 0` 처럼 변화하는 current를 조건으로 쓴 실수 → 항상 원본 n으로 나눠떨어짐 여부를 체크해야 함
3. `current = n`으로 초기화한 실수 → 시작값은 "1 빼는 경우(`dp(n-1)+1`)"가 항상 가능하므로 그 값으로 시작하는 게 자연스러움

## 학습 순서 회고
- 처음엔 Top-down을 바로 구현하려다 막힘 → 재귀 자체가 손에 안 익은 게 원인으로 판단
- 10872(팩토리얼), 10870(피보나치) 순수 재귀로 먼저 연습 → 17478(재귀함수가 뭔가요) 재귀 출력 연습
- 재귀 감 잡은 뒤 1463 Top-down 재도전 → 손으로 호출 스택 그려보며 완전히 이해
- Bottom-up은 점화식을 비교적 수월하게 세우는 편이었으나 Top-down은 "재귀 함수가 자기 자신을 호출하고 값을 리턴받는 흐름"에 대한 이해가 선행되어야 한다는 걸 체감함
