# 문제
- 방향 없는 그래프가 주어졌을 때, 연결 요소(Connected Component)의 개수를 구하는 프로그램을 작성하시오.

# 입력
- 첫째 줄에 정정의 개수 N과 간선의 개수 M이 주어진다.(1 <= N <= 1,000, 0 <= M <= N x (N-1) / 2 )
- 둘째 줄부터 $M$개의 줄에는 간선의 양끝 점 u와 v가 주어진다 (1 <= u, v <= N, u != v) 같은 간선은 한 번만 주어진다.

## 입력 1
```
6 5
1 2
2 5
5 1
3 4
4 6
```

## 출력 1
```
2
```

## 입력 2
```markdown
6 2
3 4
4 2
```

## 출력 2
```markdown
4
```
