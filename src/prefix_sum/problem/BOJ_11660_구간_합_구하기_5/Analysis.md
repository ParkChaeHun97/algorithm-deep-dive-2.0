# 분석

## 1. 문제 분석
```text
1 2 3 4
2 3 4 5
3 4 5 6
4 5 6 7
```
- 2 2 3 3이 주어지면 [2][2] 위치에서 [3][3]위치까지의 직사각형 누적합을 구하는 문제

## 2. 문제 해결

### 2.1. 2차원 배열 누적합 빌드
![2차원 배열 누적합 빌드](./src/week_02_Math/BOJ_11660_구간_합_구하기_5/2차원 배열 누적합 빌드.png)
- 각각의 인덱스 위치는 해당 위치의 직사각형 누적합 값임
- D[i][j] = D[i][j-1] + D[i-1][j] - D[i-1][j-1] + current
  - [i][j-1]는 왼쪽 idx인데, 왼쪽에서의 직사각형 누적합이 더해져있음
  - [i-1][j]는 위쪽 idx인데, 위쪽에서의 직사각형 누적합이 더해져있음
  - 만약 [i][j]가 [2][2]이면
     - [i][j-1]은 [2][1] 위치 이고 위의 [1][1]과 합쳐진 누적합임
     - [i-1][j]은 [1][2] 위치 이고 왼쪽의 [1][1]과 합쳐진 누적합임
     - [i-1][j-1]을 빼주는 이유는 왼쪽과 위쪽의 누적합이 더해짐으로 인해서 2번 겹쳐진 부분이기 때문에 한 번 뺴줌
     - 그래서 5 + 3 - 1 + 5 = 12임

### 2.2. 직사각형 누적합 출력
![2차원 배열 누적합 출력](./src/week_02_Math/BOJ_11660_구간_합_구하기_5/2차원 배열 누적합 출력.png)
- [2][2], [3][3] 크기 구하기
  - 3,3은 1,1부터의 3,3까지 사각형의 누적합 값임
  - result = D[x2][y2] - D[x1-1][y2] - D[x2][y1-1] + D[x1-1][y1-1]
    - [x2][y2] 는 범위중 가장 오른쪽 꼭지점이며 1,1부터 누적합 값임
    - [x-1][y2]는 구하고자 하는 사각형의 위쪽에 포함되지 않는 경계 행을 통쨰로 날리는 값임
    - [x2][y-1]는 구하고자 하는 사각형 왼쪽에 포함되지 않는 경계 열을 통쨰로 날리는 값임
    - [x1-1][y1-1]을 더하는 이유는 마찬가지로 행열이 겹쳐진 부분을 뺴버렸기 때문에 한번 더해줘야함
    - 그래서 45 - 12 - 6 + 1 = 28

## 2. 시간 복잡도 분석
- 표의 크기 N은 1 <= 1,024
- 합을 구해야 하는 횟수 M은 1 <= 100,000 

### 2.1. 단순한 반복문일 경우
- 먼저 배열에 build는 O($N^2$) = 1,024 * 1,024 = 1,048,576
- 누적합 구하기 횟수는 O($N^2$) * M = 104,857,600,000
- 제한 시간 1초 (100,000,000) 이면 택도 없음 약 1000배 모자름

### 2.2. 누적합 방식일 경우
- 누적합 배열에 build는 O($N^2$) = 1,048,576
- 사각형 누적합 구하기 공식 + 누적합 구하기 횟수
  - (O($N^2$) + O(1) * M) = 1,148,576
- 제한 시간 1초 (100,000,000) 이면 1000 분의 1
