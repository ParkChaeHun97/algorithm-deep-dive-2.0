# 문제
$1$번부터 $N$번까지 번호가 매겨진 $N$명의 사람이 있고, 이들 사이의 친구 관계(간선)가 주어집니다.특정 사람 $X$의 '케빈 베이컨 수'란, $X$에서 출발하여 나머지 모든 사람에게 도달하기 위한 최단 거리의 총합을 의미합니다.  

그래프에 존재하는 모든 사람의 케빈 베이컨 수를 각각 구한 뒤, 그 값이 가장 작은 사람의 번호를 출력하시오. (단, 가장 작은 사람이 여러 명일 경우 번호가 가장 작은 사람을 구한다.)

# 입력
첫째 줄에 유저의 수 $N$ ($2 \le N \le 100$)과 친구 관계의 수 $M$ ($1 \le M \le 5,000$)이 주어집니다.  
  
둘째 줄부터 $M$개의 줄에는 서로 친구인 두 사람의 번호 $A, B$가 주어집니다. (간선의 가중치는 모두 1이며, 양방향 간선입니다.)

# 출력
케빈 베이컨 수가 가장 작은 사람의 번호를 출력한다.  

## 입력 1
```
5 5
1 3
1 4
4 5
4 3
3 2
```

## 출력 1
```
1
```
