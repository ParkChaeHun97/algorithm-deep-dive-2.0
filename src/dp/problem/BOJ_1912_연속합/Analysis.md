## 백준 1912 - 연속합

### 문제
n개의 정수 수열에서 연속된 부분(1개 이상)을 선택해 만들 수 있는 최대 합을 구하는 문제.
음수가 포함 될 수 있음

### 접근
 - dp[i] = i번째 수를 반드시 포함하는 최대 연속합
 - 점화식: dp[i] = max(arr[i], dp[i-1] + arr[i])
   - 이전까지의 연속합이 음수면 버리고 arr[i] 혼자 새로 시작하는게 유리
   - 양수면 이어붙이는 게 유리
 - 최종 답은 dp 배열 전체 중 최댓값 (구간이 어디서 끝나든 확인 해야함)
 - 공간 최적화: dp[i]는 dp[i-1]만 있으면 계산 가능 배열 대신 변수 하나로 대체
   - O(n) -> 공간을 O(1)로 축소
 
### 헷갈렸던 지점
 - i번째 수를 반드시 포함한다는 정의 자체가 와닿지 않음
 - 구간 끝이 i로 고정된 경우의 최댓값이라는 의미로 이해하니 나머지 로직이 자연스러워 짐
 - 처음엔 슬라이딩 윈도우도 가능하겠다 싶었으나 음수가 섞여있고 윈도우를 넓힐지 줄일지의 기준이 없다는걸 깨달음

### 회고
- 처음에 문제를 보다 어렵게 느꼈음, dp[i]의 정의를 명확히 하고 나니 점화식이 자연스럽게 나옴
- 정의부터 명확히 하기가 DP 문제 접근의 핵심이라는 걸 깨달음
