# 거리두기 확인하기 (2021 카카오 채용연계형 인턴십, 프로그래머스 Lv2)

## 문제

5x5 대기실 5개에서 응시자(P)끼리 맨해튼 거리 2 이하로 앉으면 안 됨. 단 사이가 파티션(X)으로 막혀 있으면 허용. 대기실마다 모두 지키면 1, 한 명이라도 못 지키면 0을 담아 반환하기. 빈 테이블은 O.

## 접근

- 대기실마다 P를 만날 때마다 그 P에서 BFS를 돌림. 이동은 빈 테이블(O)로만 가능하고 X는 지나가지 못함
- BFS 깊이는 2까지만 봄. 큐에서 꺼낸 칸의 거리가 1보다 크면 더 확장하지 않고, 이웃에서 다른 P를 만나면 바로 0 반환. 거리 1(바로 옆)과 거리 2(사이에 O가 있는 직선, 대각선)가 이 한 번의 탐색으로 다 잡힘
- X로 막힌 경우는 O가 아니라서 큐에 안 들어가기 때문에 자연스럽게 허용됨. 대각선은 사이 두 칸 중 하나라도 O면 위반이라는 규칙도 BFS가 길이 있는지를 보니까 따로 분기하지 않아도 맞음
- 방 하나의 결과는 P마다의 결과 중 하나라도 0이면 0으로 유지

## 헷갈렸던 지점

- 없음. 접근은 처음부터 맞았고, 아래 두 가지 사소한 실수 때문에 채점에서 틀렸음

## 실수

1. 시작한 P 자신을 "다른 P"로 센 것
    - 시작 칸 P에서 O로 나갔다가 그 O에서 이웃을 볼 때, 되돌아와서 시작 P를 만나면 `else if (...equals("P")) return 0`이 실행됐음
    - 그래서 주변에 빈 칸이 하나라도 있는 P는 혼자 있어도 0이 나왔음. 혼자 있는 P 한 명짜리 방도 0이 나왔음
    - 시작 칸은 이미 `visited`가 찍혀 있으니까 이웃을 볼 때 `!visited`를 먼저 확인하도록 수정해서 해결
2. P마다 결과를 덮어써서 마지막 P만 반영된 것
    - `result = bfs(j, k, room)`으로 대입해서, 앞쪽 P가 0을 내도 뒤쪽 P가 1을 내면 1로 덮였음. 방 하나의 결과가 행 우선 순서의 마지막 P의 검사 결과가 돼 버렸음
    - `if (bfs(...) == 0) result = 0`으로 바꿔서 한 번 0이 나오면 유지되게 수정
3. 참고: `dr`, `dc`는 4방향인데 반복문이 `i < 3`이라 오른쪽 방향을 안 보고 있었음. 거리 2 이하인 두 P는 둘 중 한 명에게서 위, 아래, 왼쪽만으로 반드시 닿아서 답은 안 바뀌었음. 그래도 의도와 다르고 이 사실에 기대면 위험해서 `i < 4`로 고침

## 토론한 내용

- 공식 예제는 고치기 전 코드도 `[1, 0, 1, 1, 1]`로 맞게 나왔음. 방마다 마지막 P의 결과가 우연히 정답과 같았기 때문이었고, 채점은 31개 중 9개(30.9점)만 통과함
- 풀이 본문 없이 반례를 요청해서, 이 문제의 BFS 풀이가 흔히 틀리는 지점을 5x5 방 10개로 만들어 받았음. 대각선에서 한쪽만 X인 경우(위반), 둘 다 X인 경우(안전), 가로/세로 사이가 X 또는 O인 경우, 거리 3, 앞쪽 위반 뒤쪽 안전(또는 반대), 모서리에서 인접한 경우
- 이 반례에서 고치기 전 코드는 전부 0이 나왔고, 고친 뒤에는 기댓값과 정확히 일치했음
- 기댓값은 쌍 비교 방식(모든 P 쌍의 거리와 사이 칸으로 판정)과 BFS 방식 정답 코드를 따로 짜서 랜덤 방 10만 개에서 둘이 같은 결과를 내는 걸 먼저 확인한 뒤 구했음

## 회고

- 로직은 거의 맞았는데 사소한 실수 두 개가 점수를 거의 다 날렸음. 하나는 시작 칸 자기 자신을 다시 만나는 문제, 하나는 결과를 덮어쓰는 문제임
- 예제가 통과해도 안 되는 케이스가 또 나왔음. 폰켓몬, 바이러스 파이프와 같은 계열로, 예제가 우연히 버그를 가려줬음. "한 명이라도 틀리면 0"처럼 하나라도 위반하면 전체가 실패하는 조건에서는 대입이 아니라 누적(AND)으로 처리해야 함
- BFS에서 탐색 대상(시작 칸)과 같은 종류의 칸을 만났을 때 자기 자신을 걸러내는 `visited`를 확인하는 습관이 필요함. 컬러링북 때 정리한 "방문은 넣는 시점에 찍기"와 이어지는 내용임
- 반례를 직접 만들 때는 규칙에서 갈리는 지점(대각선은 둘 다 X여야 하고 직선은 가운데만 X면 되는 점, 거리 3의 경계)을 하나씩 따로 쪼개서 방을 만들면 어디가 틀렸는지 바로 보임
