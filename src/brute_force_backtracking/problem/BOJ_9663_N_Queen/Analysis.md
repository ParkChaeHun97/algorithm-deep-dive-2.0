## 백준 9663 - N-Queen

### 문제
N*N 체스판에 퀸 N개를 서로 공격할 수 없게 배치하는 경우의 수를 구하는 문제.
퀸은 같은 행/열/대각선의 말을 공격 가능. 백트래킹에 "가지치기" 개념이 추가되는 문제.

### 접근
- 퀸을 한 행에 하나씩만 놓으면 되므로, row를 depth로 삼아 "각 행마다 어느 열에 놓을지"를
  결정하는 구조 (순열/조합 때의 depth 개념과 동일한 역할)
- 열 체크(`colUsed[]`)에 더해 대각선 두 방향을 체크하는 배열이 추가로 필요
    - 우하향 대각선(↘): 같은 대각선 위의 칸들은 `row - col` 값이 항상 동일 → 이 값을 인덱스로 사용
    - 우상향 대각선(↗): 같은 대각선 위의 칸들은 `row + col` 값이 항상 동일 → 이 값을 인덱스로 사용
- `row - col`은 음수가 나올 수 있어 배열 인덱스로 못 쓰므로 `+ (N-1)` 오프셋을 더해 항상
  양수 범위(0 ~ 2N-2)로 매핑
- 열/대각선 체크에 걸리면(`isValid` 조건 불충족) 아예 그 방향으로 재귀를 들어가지 않고
  즉시 건너뛰는 것이 가지치기 — 순열/조합의 "일단 다 넣고 완성 후 걸러내는" 방식과 달리
  탐색 자체를 조기에 차단
- 순열 때와 동일하게 배치 → 재귀 → 되돌리기(각 체크 배열 false로 복귀) 구조 유지


## 회고
- 순열/조합에서 다진 백트래킹 뼈대(선택-재귀-되돌리기)에 "가지치기"라는 새 개념이 자연스럽게
  얹히는 걸 확인함. 가지치기는 조건을 만족 못 하면 재귀 자체를 시작하지 않아 탐색량을 줄이는 것
